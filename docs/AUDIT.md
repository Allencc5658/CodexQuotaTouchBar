## 已修复的问题

1. **过量读取账户信息**：原先每次刷新都调用可能包含邮箱的 `account/read`；现在先读额度，仅在套餐字段缺失时调用。
2. **真实额度截图混入项目包**：原项目目录中的实机截图已移出公开源码；仓库只放模拟预览，并在 `.gitignore` 防止再次误提交。
3. **构建缓存与本机文件混入压缩包**：公开源码 ZIP 从 Git 文件清单生成，而不是直接压缩整个工作目录。
4. **子进程可能无限等待**：超时先发 SIGTERM，仍不退出则发 SIGKILL；已用忽略 SIGTERM 的模拟服务验证。
5. **测试隐含依赖 ripgrep**：测试改用 macOS 自带的 `grep`。
6. **服务断开可能导致 SIGPIPE**：写入管道前启用 `F_SETNOSIGPIPE`，并处理短写与 `EPIPE`；模拟服务主动断开时应用返回错误，不被信号杀死。

## 仍需在公开二进制前完成

- 当前 App 是 ad hoc 签名。`codesign` 验证通过，但 `spctl`/Gatekeeper **拒绝**将其作为可信下载版；尚无 Developer ID 签名、公证或跨机器安装验证。见 [RELEASE.md](RELEASE.md)。
- Touch Bar 常驻使用私有 AppKit selector 和 `DFRFoundation`，存在系统版本兼容风险，不适合 Mac App Store。
- 仅在 Intel macOS 13.7.8 运行过实机；Apple Silicon、新系统版本及“登录时启动”交互还需独立测试。
- 当前 Bundle ID `local.codex.quota.touchbar` 是本地标识；公开二进制前应由维护者换为受控的唯一 ID，并规划设置迁移。
- Codex app-server 协议字段和桌面 App 内的 CLI 路径可能变化。维护者应在依赖版本更新后复测。
